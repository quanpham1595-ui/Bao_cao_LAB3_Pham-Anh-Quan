# ESP32 FIRE ALARM SYSTEM

## 1. Giới thiệu
Hệ thống báo cháy gia đình sử dụng ESP32 để giám sát khí gas/khói và nhiệt độ môi trường.

## 2. Phần cứng
- ESP32
- Cảm biến MQ-2
- Cảm biến nhiệt độ DHT22
- Relay điều khiển quạt
- Relay điều khiển bơm
- LED xanh và LED đỏ

## 3. Công nghệ sử dụng
- Arduino IDE
- Wokwi Simulator
- FreeRTOS
- MQTT Protocol
- HiveMQ Broker
- HTML, CSS, JavaScript

## 4. Chức năng
- Giám sát khí gas/khói.
- Giám sát nhiệt độ.
- Cảnh báo khi vượt ngưỡng.
- Điều khiển quạt và bơm.
- Chuyển đổi chế độ AUTO/MANUAL.
- Hiển thị dữ liệu trên Web Dashboard.
- Truyền dữ liệu qua MQTT.

## 5. Cấu trúc thư mục
- Arduino: Mã nguồn ESP32.
- Wokwi: Sơ đồ mạch mô phỏng.
- Web: Giao diện giám sát.
- Report: Báo cáo dự án.
